# Saia da 5ª Série

Primeira parte do projeto Flutter: definição do layout da página principal.

## Proposta

O aplicativo é uma central de estudos leve e divertida para estudantes que estão saindo da 5ª série. A tela inicial apresenta a saudação, o progresso da matéria em andamento, as disciplinas disponíveis e um desafio diário.

Além da página principal exigida na atividade, o projeto já possui layouts complementares para Aprender, Conquistas e Perfil, acessíveis pela navegação inferior.

## Como executar

Com o Flutter instalado, execute:

```bash
flutter pub get
flutter run
```

O nome técnico do projeto é `saia_da_5_serie`, enquanto o nome exibido para a pessoa usuária é **Saia da 5ª Série**.
